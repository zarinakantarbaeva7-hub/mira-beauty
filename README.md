# Mira Beauty — готовый проект для VS Code

**Публикация без Python-сервера:** [GitHub Pages](docs/GITHUB_PAGES.md). В этой версии работают просмотр страниц, фотографии, фильтры и галерея; онлайн-запись и админка отключены. Исходный Flask-проект сохраняется.

Все файлы сайта находятся в одной папке. Начните с **НАЧНИ_ЗДЕСЬ.txt**.

## Открыть код

Полностью распакуйте Mira-Beauty.zip, откройте папку Mira-Beauty и дважды нажмите **OPEN_VSCODE.bat**. Откроется рабочая область Mira-Beauty.code-workspace. Если автоматическое открытие не сработало, выберите эту папку через **File → Open Folder** в VS Code.

| Файл или папка | Назначение |
| --- | --- |
| app.py | Бэкенд Python / Flask: маршруты, форма, вход администратора, SQLite |
| data.py | Услуги, мастера и галерея |
| templates/ | Все HTML-страницы, общий шаблон и карточки |
| static/style.css | Оформление и адаптивность |
| static/script.js | Фильтры, галерея, форма и запросы к серверу |
| static/images/ | 19 разных настоящих фотографий и значок сайта |
| operator_app.py | Отдельное приложение Python / Tkinter для локальной базы |
| wsgi.py | Точка входа для Python-хостинга |
| docs/ | Инструкция публикации, план защиты, источники фото и проверки |

## Локальный просмотр

Нужен установленный Python 3.10+. Дважды нажмите **START.bat**. Он создаст .venv, установит requirements.txt и предложит создать администратора. Для логина нажмите Enter (admin), затем введите и повторите пароль от 8 символов. Пароль не отображается при вводе.

Сайт откроется на **http://127.0.0.1:5019**. Окно запуска должно оставаться открытым. Для остановки нажмите Ctrl+C. Если порт занят, остановите предыдущий запуск этого проекта.

Для запуска через F5 сначала остановите сайт в окне START.bat сочетанием Ctrl+C, затем в VS Code выберите конфигурацию «Mira Beauty: сайт». Установите рекомендуемые расширения Microsoft Python и Python Debugger, если VS Code предложит их.

Для запуска оператора из терминала проекта:

```powershell
.\.venv\Scripts\python.exe operator_app.py
```

Локальные заявки, администратор и секрет сессии создаются в instance. Чтобы сохранить данные, не удаляйте эту папку. В архив не включены чужие пароли, заявки или готовое окружение.

## Ссылка для защиты без локального терминала

Выбранный вариант без Python-сервера — [GitHub Pages](docs/GITHUB_PAGES.md). Один раз включите Source: GitHub Actions в Settings → Pages и запустите Publish GitHub Pages из вкладки Actions. После успешной публикации сайт открывается по ссылке при закрытом VS Code и выключенном компьютере; последующие изменения main публикуются автоматически. В этом режиме доступны просмотр, поиск, фильтры и галерея; запись и админка отключены.

Если для защиты понадобятся настоящая онлайн-запись, серверная база и веб-админка, используйте [размещение полной Flask-версии](docs/РАЗМЕЩЕНИЕ.md). Одного наличия репозитория недостаточно: публикация считается завершённой после успешного deploy и проверки выданной ссылки.

Локальная и серверная базы отдельные. После публикации используйте веб-админку опубликованного сайта; локальный Tkinter-оператор автоматически с ней не синхронизируется.

## Что реализовано

Главная, каталог с поиском и фильтрами, мастера, портфолио с увеличением фото, страница студии, онлайн-запись, обработка неверных данных, кабинет администратора, статусы и CSV. Свободное время зависит от мастера, длительности и занятых интервалов. Учётные записи защищены хешированием паролей, запросы изменения проверяют CSRF, SQL использует параметры.

Учебный проект: цены, сотрудники и названия демонстрационные. Фотографии Pexels не изображают реальных сотрудников Mira Beauty. Реальные услуги не оказываются, платежи и SMS не предусмотрены. Контакт проекта: **+7 776 997 60 16**. Для тестовых записей используйте вымышленные контакты.
