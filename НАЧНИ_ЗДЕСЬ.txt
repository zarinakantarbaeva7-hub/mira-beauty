MIRA BEAUTY — ГОТОВЫЙ ПРОЕКТ

Все файлы уже созданы. Создавать их вручную и копировать код из чата не нужно.

1. Нажмите правой кнопкой по Mira-Beauty.zip → «Извлечь всё».
2. Откройте распакованную папку Mira-Beauty.
3. Дважды нажмите OPEN_VSCODE.bat — откроется весь проект в VS Code.
   Если не открылся: VS Code → File → Open Folder → выберите эту папку.
4. Откройте app.py — это Python-бэкенд.
   Папка templates — HTML-страницы; static — CSS, JavaScript и фотографии.

ПОСМОТРЕТЬ САЙТ НА КОМПЬЮТЕРЕ
Дважды нажмите START.bat. При первом запуске нужен интернет.
Для логина администратора можно просто нажать Enter: будет admin.
Придумайте пароль от 8 символов и введите его дважды.
При вводе пароль не отображается — это нормально.
После запуска откроется http://127.0.0.1:5019.
Пока работает локальный сайт, оставляйте окно запуска открытым.

ПУБЛИЧНАЯ ССЫЛКА ДЛЯ ЗАЩИТЫ
В папке docs откройте РАЗМЕЩЕНИЕ.md.
Код берётся из вашего GitHub, Python-сервер работает на PythonAnywhere.
После размещения ссылка открывается без локального терминала и VS Code.
Публикация выполняется отдельно в вашем аккаунте хостинга.

План защиты: docs/ЗАЩИТА.md.
Заявки и администратор сохраняются в instance; папка появится при запуске.
Эта папка, .venv и пароли в архив не включены: настройка начинается с нуля.
