# Размещение Mira Beauty на PythonAnywhere

PythonAnywhere поддерживает Flask и SQLite. Бесплатный аккаунт предоставляет один сайт на поддомене пользователя. У такого сайта ограниченный срок активности — один месяц; продление выполняется в панели сервиса. Проверьте текущие условия при регистрации: [официальные возможности бесплатного аккаунта](https://help.pythonanywhere.com/pages/FreeAccountsFeatures/) и [тарифы](https://www.pythonanywhere.com/pricing/).

Эта инструкция описывает самостоятельное размещение. Она не означает, что сайт уже опубликован. Пользовательский адрес выдаётся после создания аккаунта; `USERNAME` ниже нужно везде заменить реальным именем аккаунта.

## 1. Подготовить проект

Создайте аккаунт PythonAnywhere и войдите в него. Загрузите исходники проекта через вкладку **Files** либо клонируйте свой публичный репозиторий в **Consoles → Bash**. Пример клонирования текущего репозитория:

```bash
git clone https://github.com/zarinakantarbaeva7-hub/mira-beauty.git
```

Найдите папку, в которой лежат актуальные `app.py` и `requirements.txt`. Дальнейшие примеры предполагают путь `/home/USERNAME/mira-beauty`. Если файлы находятся в подпапке репозитория, в командах и настройках укажите путь к этой подпапке.

Не загружайте Windows-папку `.venv` и локальную базу с контактами. Окружение и новая серверная база создаются на хостинге.

## 2. Создать окружение

В Bash-консоли перейдите в папку проекта:

```bash
cd /home/USERNAME/mira-beauty
python3 --version
```

Нужен Python 3.10 или новее. Выберите версию Python, которая доступна и в консоли, и в настройке веб-приложения. Если в консоли `python3` указывает на другую версию, используйте её явное имя, например `python3.13`.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py setup-admin
```

Запомните введённые логин и пароль администратора. Пароль не отображается при вводе. Отдельный сервер через `python app.py` здесь постоянно запускать не нужно: приложение будет обслуживать WSGI-система PythonAnywhere.

## 3. Создать веб-приложение

Откройте **Web → Add a new web app**. Выберите бесплатный адрес аккаунта, затем **Manual configuration** и ту же версию Python, которой создана `.venv`.

В настройках Web укажите:

| Поле | Значение с вашим USERNAME |
| --- | --- |
| Source code | `/home/USERNAME/mira-beauty` |
| Working directory | `/home/USERNAME/mira-beauty` |
| Virtualenv | `/home/USERNAME/mira-beauty/.venv` |

Откройте ссылку **WSGI configuration file**, замените шаблонный код следующим и сохраните:

```python
import os
import sys

os.environ["MIRA_HTTPS"] = "1"

project_path = "/home/USERNAME/mira-beauty"
if project_path not in sys.path:
    sys.path.insert(0, project_path)

from app import app as application
```

Здесь тоже замените `USERNAME`. Если проект лежит глубже, исправьте `project_path`. `MIRA_HTTPS=1` включает передачу сессионной cookie только по HTTPS; открывайте опубликованный сайт по HTTPS. В WSGI-файле не должно быть `app.run()`.

В разделе **Static files** добавьте:

| URL | Directory |
| --- | --- |
| `/static/` | `/home/USERNAME/mira-beauty/static/` |

## 4. Перезагрузить и проверить

Нажмите **Reload** на вкладке Web и откройте адрес, который показан в панели. Используйте именно выданный сервисом адрес.

Проверьте главную страницу, каталог, мастеров, портфолио и форму. Отправьте заявку с вымышленными контактами, затем войдите в веб-админку и найдите её. Проверьте страницу с телефона через мобильный интернет: так вы убедитесь, что это публичная ссылка, а не локальная сеть.

Если показана ошибка, откройте **Error log** на вкладке Web. Проверьте путь к проекту, выбранный Python, virtualenv и установленные зависимости. После изменения Python-кода нажимайте Reload.

## 5. Хранение данных и обслуживание

SQLite создаётся в `instance/beauty.sqlite3` внутри проекта. Файлы аккаунта PythonAnywhere сохраняются на его файловой системе; не удаляйте базу и секрет сессии при обновлении исходников. При необходимости можно указать отдельный постоянный путь через `MIRA_DATABASE` до импорта приложения в WSGI. Секрет `MIRA_SECRET_KEY`, если задан, должен быть длинным случайным значением и храниться приватно.

Проверяйте в панели дату окончания активности бесплатного сайта и продлевайте его заранее. Периодическая перезагрузка страницы посетителем не заменяет действие продления в панели.

Локальный сайт на компьютере и размещённый сайт используют разные базы. Веб-админка показывает серверные записи; локальный Tkinter-оператор — локальные. Автоматической синхронизации между ними нет.

До публикации используйте демонстрационные данные. Для учебной защиты сохраните локальную рабочую копию проекта: она позволит показать код и взаимодействие frontend/backend даже без интернета.
