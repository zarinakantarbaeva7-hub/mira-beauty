# Проверка обновления фотографий и текста

В GitHub Actions выполнены 23 автоматических теста Flask, проверка 19 разных локальных JPEG и Chromium на ширинах 360, 390, 768, 1000 и 1440 пикселей. Проверены загрузка всех фотографий, отсутствие прежних заглушек m. и SVG-иллюстраций в фотографиях, отсутствие горизонтального переполнения, размер основного шрифта от 17px, описание услуг от 16px, контактный телефон и мобильное меню. Ошибок JavaScript в проверенных сценариях не обнаружено. Публичное размещение Flask-сервера этим не подтверждается.
