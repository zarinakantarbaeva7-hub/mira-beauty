# Публикация через GitHub Pages

Это статическая версия сайта: страницы, изображения, каталог с поиском и фильтрами, портфолио и мобильное меню. Форма записи и вход администратора в этой опубликованной версии отключены. Данные заявок не отправляются и не сохраняются. Python-бэкенд остаётся в исходниках и работает при обычном локальном или WSGI-запуске.

## Один раз включить

1. Откройте https://github.com/zarinakantarbaeva7-hub/mira-beauty/settings/pages
2. В Build and deployment → Source выберите **GitHub Actions**.
3. Откройте Actions → **Publish GitHub Pages** → **Run workflow** → ветка main → **Run workflow**.
4. Дождитесь зелёных build и deploy. Ссылка сайта: https://zarinakantarbaeva7-hub.github.io/mira-beauty/

Если первый deploy завершился ошибкой, сначала проверьте Source в Settings → Pages, затем повторите workflow. Скрипты не могут включить эту настройку через доступное подключение GitHub.

## Как обновлять

После изменения и сохранения исходников в main GitHub Actions заново собирает страницы и публикует результат. Проверяйте зелёную галочку в Actions. Повторно загружать старый ZIP не нужно. Загрузка ZIP в репозиторий не распаковывает и не обновляет исходники. Локальные файлы на компьютере сами от изменений GitHub не меняются.

HTML собирается из templates/, данные каталога берутся из data.py, оформление и фото — из static/. Опубликован только _site: базы, пароли, исходники Python и download-архив в сайт не попадают.
