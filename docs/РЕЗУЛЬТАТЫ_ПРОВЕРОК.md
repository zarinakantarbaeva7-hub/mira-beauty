# Результаты проверки готовой версии

Проверено 21 октября 2026 года на Python 3.12 / Linux и Chromium. Исходный проект рассчитан на Python 3.10+; у пользователя установлен Python 3.13.

## Автоматические тесты

`python -m unittest discover -s tests -v`: **23 теста прошли**.

Проверены публичные страницы и 404, каталог и совместимость мастеров, реальные записи SQLite, неверные поля без сохранения, CSRF включая Unicode-токен, повреждённый и слишком большой JSON, SQL-параметры, экранирование пользовательского текста, пересечения процедур разной длительности, одновременные запросы (один получает 201, второй 409), вход/выход, закрытые страницы и CSV, отмена и восстановление записей, создание администратора и миграция старой базы без потери заявок.

## Проверки в браузере

Пройдены 8 публичных страниц, поиск и фильтры каталога, пустое состояние, просмотр портфолио в диалоге, серверная ошибка неверного телефона, успешная запись с номером, отображение той же заявки в админке и исключение занятого интервала из списка.

На ширинах 360, 390, 768 и 1440 пикселей горизонтального переполнения страниц не обнаружено. Мобильное меню открывается и позволяет перейти к мастерам. Во время сценариев ошибок JavaScript не обнаружено. Локальные иллюстрации загружаются; 16 основных SVG имеют разное содержимое и проходят XML-проверку.

Скриншоты настоящего интерфейса с вымышленными данными находятся в `screenshots/`: `home-desktop.jpg`, `home-mobile.jpg`, `services-mobile.jpg`, `validation.jpg`, `booking-success.jpg`, `admin.jpg`.

## Проверка запуска

Проверен запуск Waitress и ответ `/api/health`. Повторный запуск на занятом порту завершается понятным сообщением с просьбой остановить предыдущий сервер; браузер с прежним сайтом при этом не открывается.

## Границы проверки

Это проверка в эмуляции размеров браузера; физический телефон не использовался. `START.bat` проверен по структуре команд, но не запускался на настоящей Windows в этой среде. Графическое окно Tkinter здесь не запускалось из-за отсутствия дисплея; код приложения оператора компилируется. Публичный Python-хостинг не подключён: доступ по внешней HTTPS-ссылке и сохранность серверной базы после перезапуска пока не проверены.
